# Sidebar

## What is the Sidebar?

The **Sidebar** is the main navigation tool.&#x20;

1. **Vault Sidebar** — to move between all channels in your Vault.&#x20;
2. **Channel Sidebar** — to create, navigate, and organize everything in your Channel.&#x20;

### Vault Sidebar

Here you can add new channels and quickly navigate between the existing ones you are part of. Additionally, you can also find your [account-and-data.md](../advanced/settings/account-and-data.md "mention"), [keyboard-shortcuts.md](../advanced/settings/keyboard-shortcuts.md "mention"), and access [Resources](https://app.gitbook.com/s/uI82XLdf1100Q75OKbEQ/resources "mention") here.&#x20;

### Channel Sidebar

#### Header

At the very top, you'll see your Channel name and icon. You'll also find:&#x20;

* **Create** — instantly add a new Object. The dropdown button reveals more creation options.
* **Search** — find any Object in this Channel.
* **Members** — see who's in the Channel and their roles.
* **Channel Menu** — access to Settings and Manage Sections in your sidebar.

#### Sections

Below the header, sections appear in this order by default:

1. **Pins** — Objects for everyone, set by the channel Owner.
2. **Favorites** — Objects for only you, set by you.
3. **Unread** — Notifications that display temporarily.&#x20;
4. **Recently Edited** — Objects modified recently.
5. **Types** — Objects grouped by Type.&#x20;
6. **Bin** — Objects archived that await permanent deletion.&#x20;

Each section can be hidden, reordered, or fine-tuned. See [sidebar-sections.md](../your-workspace/customize-and-edit-the-sidebar/sidebar-sections.md "mention") for details.

## Sidebar Settings

### Resize and Collapse

Drag the right edge of the Sidebar to resize it. You can:

* Make it wider for more space
* Make it narrower to save space
* Collapse it entirely by dragging the edge to the left until it disappears
* Turn on auto show/hide the sidebar in your [account-and-data.md](../advanced/settings/account-and-data.md "mention")

### Compact Vault Sidebar

To gain more visual space, the **Vault** has a compact mode. Drag the Vault's right edge to make it narrower past a threshold and it'll automatically switch to compact mode. Drag the edge wider to return to the regular Vault Sidebar layout.&#x20;

This narrow and compact Vault layout helps to provide more content space. The Channel sidebar can also be resized for even more room.

### Focus Mode

To quickly switch to a focus mode, you can assign a keyboard shortcut to toggle on and off the **Vault** and **Channel Sidebar** at the same time. This hides both sidebars for maximum content space.&#x20;

1. Open **Vault Settings > Application > Keyboard Shortcuts**.
2. Find **Toggle Vault & Channel Sidebar**.
3. Assign a shortcut.

## Tips

{% hint style="info" %}
**Focus Mode with Tabs is handy for removing distractions from other channels.** When you're deep in work, hide both sidebars so you don't get distracted by other Channels and their notification badges. You can setup a custom keyboard shortcut to make this even faster.&#x20;
{% endhint %}

{% hint style="info" %}
**Pin a Query, not just static Objects.** A pinned Query like "Tasks where Status = In Progress" or "Notes where Modified is this week" acts as live [sidebar-widgets.md](../your-workspace/customize-and-edit-the-sidebar/sidebar-widgets.md "mention") — it updates itself as your data changes.
{% endhint %}

{% hint style="info" %}
**Switch to Links mode for archive Channels.** A Channel where you mostly read rather than create can benefit from the denser Links view — you see more at once.
{% endhint %}
