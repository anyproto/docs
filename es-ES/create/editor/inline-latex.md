# LaTeX insertado

El LaTeX insertado permite escribir notación matemática o científica en una línea de texto, sin tener que separarlo en un bloque aparte. En lugar de colocar una ecuación en una línea aparte, el LaTeX insertado permite que la fórmula aparezca de forma natural entre las palabras que la rodean.

## Cómo usar LaTeX

Para escribir LaTeX en la línea de la frase, delimita la notación matemática con símbolos `$`:

```
La fórmula de la energía es $E = mc^2$. 
```

Puedes crear un bloque entero con `/latex` para aprovechar por completo el sistema de composición de fórmulas de LaTeX.
