# LaTeX insertado

El LaTeX insertado permite escribir notación matemática o científica en una línea de texto, sin tener que separarlo enun bloque aparte. En lugar de colocar una ecuación en una línea aparte, el LaTeX insertado permite que la fórmula aparezca de forma natural entre las palabras que la rodean.

## Cómo usar LaTeX

Para escribir LaTeX en la línea de la frase, delimita la notación matemática con símbolos `$`:

```
La fórmula de la energía es $E = mc^2$.
```

Para crear un bloque entero, usa `$$…$$` o inserta el bloque por medio de `/late`.
