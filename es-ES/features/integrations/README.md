# Integraciones

Las integraciones son la forma de conseguir que otras aplicaciones trabajen con Anytype. Para ello, puedes usar la API local, el servidor MCP o la herramienta CLI si sabes cómo hacerlo. 

Tienes más información (en inglés) en el [portal para desarrolladores de Anytype](https://developers.anytype.io/).
