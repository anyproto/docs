# Iniciativa Open Any

## **Cómo contribuir**

Si te dedicas al desarrollo y quieres contribuir al ecosistema de Anytype, consulta los documentos `CONTRIBUTING` del repositorio.

Síguenos en [GitHub](https://github.com/anyproto) y únete a la [comunidad de colaboradores](https://github.com/orgs/anyproto/discussions) para construir Anytype juntos.

Si quieres saber más sobre la decisión de abrir nuestro código, lee este artículo: 

{% embed url="https://blog.anytype.io/our-open-philosophy/" %}

Para cualquier pregunta sobre nuestras licencias, consulta [https://legal.any.coop/](https://legal.any.coop/), y para preguntas técnicas, consulta [https://tech.anytype.io/](https://tech.anytype.io/).
